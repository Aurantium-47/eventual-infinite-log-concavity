# The frozen single-node computation

This note identifies the workload, not a proof of the unresolved full target.
The executable formulas are in `certificate.py`.

The deterministic input consists of two rational endpoint candidates:

- left = 10135311763 / 50000000;
- right = 5037375689 / 25000000.

The panel uses h = 1/(64·1001), c = h, r = 4h,
t = 2/(1/left + 1/right), and a = (1/right − 1/left)t/(2h).
Let u = c + hw and B = ceil(3t/2). The truncated polynomial jets begin with
p₀ = 2^(−B), p₁ = t·2^(−B), and are generated by

    p_(k+1) = t(1 − ku)/(k+1) p_k
              + t²(2u − (k−1)u²)/(k+1) p_(k−1).

Four streaming applications of the log-concavity transform
`L(p)_k = p_k² − p_(k−1)p_(k+1)` produce the retained output sequence.
The recurrence loop runs through k=K+3, computing p through p_(K+4),
to retain K+1 outputs after four transforms. The routine evaluates that
sequence by Horner's rule at the degree-d Taylor jet of
`−(1 + ahw)^(−16)`. Every retained coefficient is enclosed as
`(m_i ± radius)/2^P`, with d=360 and P=2048.

The convolution backend only computes exact integer coefficients before
rescaling. If two input jets have integer midpoint lists m and n and common
radii R and S, the numerator error bound used by multiplication is

    S·sum(|m_i|) + R·sum(|n_i|) + (d+1)·R·S.

The code divides outward by 2^P and adds one unit to enclose midpoint rounding.
Changing the backend does not alter this formula, degree truncation, rational
scaling, or the subsequent Bernstein conversion. Rational Bernstein control
values bound the retained polynomial on w∈[−1,1]. The routine adds the separately
computed analytic parameter-Taylor and coefficient-tail bounds before declaring
a sign. Those exact rational quantities are included in the compared receipts.

The observed receipt certifies a positive sign for this one local computation.
The candidate endpoint selection itself is not a sign proof. A complete theorem
would require the other nodes, panels, ordering, joins, bulk and endpoint
arguments that this deliberately small benchmark does not contain. Identical
backends can share an error in the surrounding formulas; exact replay must not
be presented as independent validation of the whole mathematical argument.
