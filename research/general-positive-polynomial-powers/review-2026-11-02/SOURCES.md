The bundled `verify.py` is an independent implementation of the displayed initial ratios, outward-rounded recurrence, prefix restriction, and direct coefficient operator. It reconstructs before comparing to author data and does not invoke the author's implementation. The `reconstructed_*.json` files and `results.json` are generated by this implementation, not copied from the author's gzip. SHA-1 above identifies Git blobs (including the Git object header); SHA-256 hashes the file bytes directly.
